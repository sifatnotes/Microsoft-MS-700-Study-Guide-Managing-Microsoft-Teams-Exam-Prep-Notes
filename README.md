## Exam Overview

The **MS-700: Managing Microsoft Teams** exam evaluates your proficiency in configuring, deploying, and managing Microsoft Teams to enable efficient enterprise collaboration and communication across chat, channels, meetings, live events, calling, and third-party app integrations.

| Parameter | Details |
| :--- | :--- |
| **Exam Code** | MS-700 |
| **Certification Earned** | Microsoft 365 Certified: Teams Administrator Associate |
| **Question Format** | 40–60 questions (Multiple choice, drag-and-drop, case studies, build-list) |
| **Exam Duration** | 120 minutes |
| **Passing Score** | 700 / 1000 (Scaled score) |
| **Standard Cost** | ~$165 USD (Varies by country/region) |
| **Prerequisites** | None (Basic Microsoft 365 fundamentals recommended) |

---

## Who Should Take This Exam

This exam is designed for IT professionals and Microsoft Teams Administrators who:
- Configure, deploy, and manage Microsoft Teams workloads across enterprise environments.
- Manage teams, channel settings, messaging policies, meeting configurations, app policies, and PSTN voice connectivity.
- Collaborate with owners of identity, security, compliance, networking, licensing, and user adoption workloads.
